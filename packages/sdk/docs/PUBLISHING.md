# Publishing

Published npm packages from this repo are intended to include `@attestrack/types`, `@attestrack/schema`, `@attestrack/sdk`, and optionally `@attestrack/strategies` when stable.

`@attestrack/host-contracts` is publishable (zero deps). `@attestrack/host-cloudflare-worker`, `@attestrack/worker-core`, and `@attestrack/consent-js` may stay private to the monorepo until the release process is defined.

Version and provenance for **third-party** strategy packages should follow the marketplace signing rules in premium product specs (not duplicated here).
