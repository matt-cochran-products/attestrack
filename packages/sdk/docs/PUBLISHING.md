# Publishing

Published npm packages from this repo are intended to include `@attestrue/types`, `@attestrue/schema`, `@attestrue/sdk`, and optionally `@attestrue/strategies` when stable.

`@attestrue/host-contracts` is publishable (zero deps). `@attestrue/host-cloudflare-worker`, `@attestrue/worker-core`, and `@attestrue/consent-js` may stay private to the monorepo until the release process is defined.

Version and provenance for **third-party** strategy packages should follow the marketplace signing rules in premium product specs (not duplicated here).
